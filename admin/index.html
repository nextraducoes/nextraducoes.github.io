Conectar ao GitHub

O painel salva as traduções e capas diretamente no repositório nextraducoes/nextraducoes.github.io. O token fica salvo apenas no navegador do seu computador.

Como gerar seu Token (Fine-grained) em 1 minuto
  1. Acesse no GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Clique em Generate new token.
  3. Em Resource owner, escolha nextraducoes (ou sua conta com acesso).
  4. Em Repository access, selecione Only select repositories → nextraducoes.github.io.
  5. Em Permissions → Repository permissions, mude Contents para Read and write.
  6. Gere o token e cole abaixo.
